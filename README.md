# Seminar Hall Management System

## Project Overview

The Seminar Hall Management System is a web-based application developed using Python and Django. It allows users to book seminar halls online while enabling administrators to manage seminar halls and approve or reject booking requests.

## Features

- User Registration and Login
- User Dashboard
- Admin Dashboard
- Add, Edit and Delete Seminar Halls
- Upload Hall Images
- Search Seminar Halls
- Filter by Location
- Filter by Capacity
- Book Seminar Halls
- View My Bookings
- Booking Status Tracking
- Prevent Duplicate Bookings
- Prevent Overlapping Bookings
- Approve or Reject Booking Requests

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite

## Installation

1. Clone the repository.
2. Open the project folder.
3. Install dependencies:

```
pip install -r requirements.txt
```

4. Apply migrations:

```
python manage.py migrate
```

5. Run the server:

```
python manage.py runserver
```

6. Open:

```
http://127.0.0.1:8000/
```
